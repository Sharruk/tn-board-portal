SECTION 5 — DEPLOYMENT CONFIGURATION
====================================================

BEFORE (broken — ran Flask):

AFTER (fixed — runs FastAPI with built React frontend):
  run = ["sh", "-c", "cd frontend && npm run build &&
         cd ../backend && ENVIRONMENT=production
         uvicorn app.main:app --host 0.0.0.0 --port 5000"]

  deploymentTarget = autoscale  (unchanged)

HOW THE PRODUCTION SERVER WORKS:
  Step 1: npm run build compiles React into frontend/dist/
  Step 2: uvicorn starts FastAPI with ENVIRONMENT=production
  Step 3: FastAPI detects IS_PRODUCTION=True and serves:
            /assets/*    → frontend/dist/assets/ (hashed JS/CSS)
            /api/v1/*    → FastAPI routers
            /uploads/*   → local PDF files
            /* (all else) → frontend/dist/index.html (SPA fallback)
  React Router handles client-side navigation — all routes return index.html.

PORT MAPPING:
  Dev:        Vite :5000 → browser, FastAPI :8000 → Vite proxy
  Production: FastAPI :5000 → browser directly (port 80 mapped)

MODIFICATION MADE:
  backend/app/main.py updated — added production block:
    - Mounts /assets from frontend/dist/assets/
    - GET / returns index.html
    - GET /{full_path:path} catch-all returns index.html
    - Skips catch-all for /api/ and /uploads/ paths
  In development (IS_PRODUCTION=False), behavior is unchanged.
