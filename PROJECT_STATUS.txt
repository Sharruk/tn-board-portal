Files modified:
- Replit workflow updated to run FastAPI (uvicorn) instead of Flask (gunicorn)
- backend/app/services/auth.py — switched from passlib to werkzeug
  (bcrypt 5.x incompatible) and from python-jose to PyJWT (firewall blocked)

Problems encountered:
1. python-jose blocked by Replit package firewall — switched to PyJWT
2. passlib incompatible with bcrypt 5.x — switched to werkzeug.security
3. Old Flask tables (subjects, files, users etc.) had different schema —
   dropped all old tables and recreated with new schema

Solutions implemented:
1. PyJWT as JWT library (same API, no extra deps)
2. werkzeug.security for password hashing (already installed)
3. Dropped old tables via SQLAlchemy engine, recreated via Base.metadata.create_all
