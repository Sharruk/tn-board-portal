PHASE 3.7 CHANGES — Search & Content Management

1. Search Aliases (backend: app/api/papers.py)
   Added subject alias expansion before database query:
     maths / math     → mathematics
     phy              → physics
     chem             → chemistry
     bio              → biology
     sci              → science
     eng              → english
     eco              → economics
     acc              → accountancy
     hist             → history
     geo              → geography
     cs / comp        → computer science
     comm             → commerce
     qly / qtly       → quarterly
     half / hy        → half yearly
   Multi-word queries also expand each word individually.

2. Class Name Matching (backend: app/api/papers.py)
   Search now OR-filters on Class.name in addition to
   Paper.title, Paper.exam_type, Subject.name.
   Enables queries like "class 10" to work naturally.

3. Search Analytics (backend: app/services/analytics.py)
   In-memory tracking using collections.deque + defaultdict.
   Stores: last 20 search events (term, result_count, timestamp)
   Aggregates: per-term search count (resets on backend restart by design).
   New endpoint: GET /api/v1/admin/search-analytics (JWT-protected).

4. Dashboard: Popular Searches card (frontend: DashboardPage.jsx)
   Two-column layout: Recent Papers (2/3 width) + Popular Searches (1/3).
   Shows top 10 search terms with counts (e.g. "mathematics  3×").
   Empty state when no searches recorded yet.

5. Admin Upload: Per-field validation (frontend: PapersPage.jsx)
   Replaced single formError with formErrors object (per field).
   Inline error messages below each required field with red border highlight.
   Validates: classId, subjectId, examType, title before submit.

6. Admin Upload: Progress bar (frontend: PapersPage.jsx + services/admin.js)
   uploadPaper() now accepts onProgress callback.
   Uses axios onUploadProgress to track percent uploaded.
   Blue progress bar shown inside upload modal during upload.

7. Admin Toasts (frontend: PapersPage.jsx)
   Toast component (auto-dismiss 4s) shown on:
     Upload success — "Paper uploaded successfully!"
     Edit success  — "Paper updated successfully!"
     Delete success — "Paper deleted."
     Delete error  — error message from API

8. YouTube Thumbnail Preview (frontend: PapersPage.jsx)
   Both Upload and Edit modals show a live YouTube thumbnail
   after a valid YouTube URL is entered.
   Uses: https://img.youtube.com/vi/{VIDEO_ID}/mqdefault.jpg
   Graceful fallback: hides image if thumbnail fails to load.

9. Empty Search Suggestions (frontend: SearchPage.jsx)
   Clickable suggestion chips shown in two states:
     a) Initial state (no query typed yet)
     b) No-results state (query returned 0 papers)
   Chips: Mathematics, Physics, Chemistry, Biology, Science,
          Annual Exam, Quarterly Exam, Half Yearly Exam, Answer Key
