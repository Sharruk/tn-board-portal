PHASE 3.9 FEATURES

1. Bulk Upload (Admin Papers → Bulk Upload tab)
   - Select multiple PDF files at once
   - Metadata auto-extracted from filename patterns:
     Class10_Maths_Quarterly_2024.pdf → Class 10 / Mathematics / Quarterly Exam / 2024
   - Subject aliases: maths→Mathematics, phy→Physics, chem→Chemistry, bio→Biology, eng→English
   - Exam aliases: quarterly→Quarterly Exam, annual→Annual Exam, halfyearly→Half Yearly Exam, etc.
   - Per-file editable form fields (class, subject, exam type, year, title, paper type)
   - Quality warnings (non-blocking):
     * Title too short (< 10 chars)
     * Year missing
     * Duplicate filename in batch
     * Suspiciously small PDF (< 10 KB)
   - Sequential upload with per-file progress bar
   - Upload summary (succeeded / failed counts)

2. Content Status Dashboard (/admin/content-status)
   - Grid view: rows = subjects, columns = exam types
   - Exam types tracked: Annual Exam, Half Yearly Exam, Quarterly Exam, Unit Test 1/2/3
   - Green ✓ = at least one paper exists for that combination
   - Red ✗ = no paper uploaded yet
   - Per-class completion percentage
   - Overall coverage progress bar

3. Recent Upload Activity (Admin Dashboard)
   - Card showing the latest 20 uploads
   - Columns: Paper Title, Class/Subject, Exam Type, Upload Date, Uploaded By
   - Backend endpoint: GET /admin/recent-uploads?limit=20

4. CSV Export (Admin Papers page header)
   - "Export CSV" button visible when papers exist
   - Client-side CSV generation (no extra API call)
   - Columns: id, title, class, subject, exam_type, year, paper_type, download_count
   - Downloads as papers.csv

5. Content Quality Validation (Bulk Upload)
   - Warns (does not block) on: short title, missing year, duplicate filename, tiny PDF
   - Warnings shown inline per file, recalculated live as admin edits fields

====================================================

SLUG URL FORMAT

Pattern: /paper/{slugify(title)}-{id}

Examples:
  /paper/class-10-mathematics-annual-exam-2024-1
  /paper/class-10-science-quarterly-exam-2024-2
  /paper/class-11-physics-half-yearly-exam-2024-4

Backend lookup: rsplit('-', 1) extracts ID from end of slug.
Old numeric routes still work: /paper/1, /paper/2, etc.
All paper API responses include a computed `slug` field.
