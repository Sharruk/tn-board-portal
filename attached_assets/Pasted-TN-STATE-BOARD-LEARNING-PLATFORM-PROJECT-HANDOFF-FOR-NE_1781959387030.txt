====================================================
PROJECT OVERVIEW
================

Project Name:
TN State Board Learning Platform

Purpose:

A full-stack educational platform for Tamil Nadu State Board students.

Main workflow:

Question Paper
↓
Admin Upload
↓
Public Website
↓
Student Views Paper
↓
Student Downloads PDF
↓
Student Watches YouTube Explanation

This is NOT a Learning Management System (LMS).

It is a Question Paper + Answer Key + YouTube Resource Platform.

* Exam Type
* Year

bio → Biology
eng → English
