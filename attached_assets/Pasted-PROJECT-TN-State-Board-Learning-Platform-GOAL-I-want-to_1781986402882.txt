PROJECT: TN State Board Learning Platform

GOAL

I want to completely eliminate the FastAPI backend and move to a Vercel-native architecture.

FINAL TARGET ARCHITECTURE

Frontend:
- React
- Vite
- TailwindCSS

Backend:
- NONE

Database:
- Supabase PostgreSQL

Authentication:
- Supabase Auth

Storage:
- Supabase Storage

Hosting:
- Vercel

OBJECTIVE

Students should be able to:

- Browse Classes 9, 10, 11, 12
- Browse Subjects
- Search Question Papers
- View Question Papers
- Download PDFs
- Open YouTube explanation links

Admins should be able to:

- Login securely
- Upload PDFs
- Edit papers
- Delete papers
- View analytics
- View content status

NO FastAPI server should be required.

NO Railway.

NO Render.

NO Replit deployment.

Everything should run through:

React + Supabase + Vercel
