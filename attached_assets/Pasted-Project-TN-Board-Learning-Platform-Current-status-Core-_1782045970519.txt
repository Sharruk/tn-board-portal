## ISSUE 1 — Uploaded paper filename/title mismatch

Current behavior:

When I upload a paper and give a title, for example:

"Class 12 Maths Public Exam 2025"

the PDF is stored using a UUID filename:

7c01aa43-14ca-4538-9b9a-5c5363dbe138.pdf

and in some places the UUID filename is shown instead of the title I entered.

Expected behavior:

* Everywhere in the UI, show paper.title.
* Never show the UUID storage filename to users.
* UUID filename should remain internal storage only.
* Student pages, admin pages, search results, downloads, and PDF viewer labels should display the paper title.

Audit all places where filename/file_path/public_url is displayed and replace with title where appropriate.
