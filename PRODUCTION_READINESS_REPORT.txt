====================================================
BLOCKER SUMMARY
====================================================

The following must be resolved BEFORE the app goes live:

  BLOCKER 1 — Admin default password not changed
  ─────────────────────────────────────────────
  Risk: Anyone who reads this repository can log in as admin.
  Fix:  Run the password-change script in DEPLOYMENT_GUIDE.md Step 3.

  BLOCKER 2 — Local filesystem storage in production
  ──────────────────────────────────────────────────
  Risk: Every uploaded PDF is permanently lost on each Replit
        redeploy or VM restart. This affects ALL existing content.
  Fix:  Configure Supabase Storage or S3 (DEPLOYMENT_GUIDE.md Step 2)
        and implement the provider stub in storage.py.

  BLOCKER 3 — JWT_SECRET_KEY not set
  ────────────────────────────────────
  Risk: If ENVIRONMENT=production and the secret is the default,
        the server refuses to start. But in development it silently
        uses the insecure default — tokens could be forged.
  Fix:  Set JWT_SECRET_KEY in Replit Secrets before deploying.

  BLOCKER 4 — CORS_ORIGINS not set to production domain
  ───────────────────────────────────────────────────────
  Risk: Server refuses to start in production if CORS_ORIGINS=*.
  Fix:  Set CORS_ORIGINS to the exact Replit deployment URL.
