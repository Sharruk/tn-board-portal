3. SHARE BUTTON TEST
====================================================

Feature:
  Share button uses Web Share API (mobile) or clipboard fallback (desktop).
  Shows toast notification on success.

Implementation:
  if (navigator.share) → await navigator.share(shareData)
  else → await navigator.clipboard.writeText(url)
  Both paths call showToast() on success.

    Result: PASS

  Case C — Both APIs unavailable (very old browsers):

    Result: PASS

====================================================
REMAINING ITEMS (not blockers)
====================================================

1. Toast animation — uses animate-fade-in class. If Tailwind doesn't
   include this utility by default, the toast will appear without fade.
   Workaround: add keyframe in tailwind.config.js if needed.
   (Pill appearance is still functional without the animation.)

2. Download attribute on <a> — for same-origin files, the `download`
   HTML attribute triggers a file save. For cross-origin (Supabase
   Storage in Phase 4), `download` may not work — a server-side
   redirect or Content-Disposition header will be required.

3. Sample download counts are all 0 — realistic counts will build
   naturally once real students use the platform.
