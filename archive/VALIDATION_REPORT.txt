DELETE TESTS
====================================================

Test: Delete paper removes DB record + uploaded file

Backend DELETE /api/v1/admin/papers/{id}:
  1. Fetches paper by ID
  2. If paper.file_path exists — calls delete_file_locally(file_path)
     which removes /uploads/<filename> from disk
  3. Deletes paper row from DB

Code review confirms:
  - File deletion uses os.remove() via delete_file_locally()
  - DB delete via db.delete(paper) + db.commit()
  - 404 returned if paper not found
  - No orphaned files left behind

Admin UI:
  - Delete button shows confirmation dialog before proceeding
  - On success, table reloads automatically

Result: PASS (code-verified)

====================================================
PROBLEMS FOUND
====================================================

Problem 1 — Database was empty on import
  On migration to Replit, the PostgreSQL database had no data.
  The app showed empty states everywhere (no classes, no subjects,
  no admin account).
  Fix: Ran backend/seed.py to populate all tables.
  Status: FIXED

Problem 2 — python-jose blocked by package firewall
  The original requirements.txt listed python-jose for JWT.
  Replit's package firewall blocked it.
  Fix: Already using PyJWT (imported as 'jwt') in auth.py —
  no code change needed, only removed python-jose from pip install.
  Status: FIXED

Problem 3 — Admin table PDF/YouTube columns showed symbols only
  The admin papers table used "Download" link and "▶" symbol.
  Not immediately readable at a glance.
  Fix: Replaced with YES / NO pill badges (green YES, gray NO).
       YES badges are clickable links (open PDF / YouTube).
  Status: FIXED

Problem 4 — Paper detail page had no empty state for missing content
  When both PDF and YouTube URL were absent, only the amber
  "PDF not yet uploaded" warning appeared — no guidance for students.
  Fix: Added a friendly "Content coming soon" empty-state card
       shown only when both PDF and YouTube are missing.
  Status: FIXED

Problem 5 — No sample content
  The papers table was empty — impossible to test the full workflow.
  Fix: Created 5 placeholder PDFs in /uploads/ and inserted
       5 sample papers covering different classes, exam types,
       paper types, and resource combinations.
  Status: FIXED
