TASK 7 — SEO SLUG URLS

STATUS: COMPLETE

Slug format: {slugify(title)}-{id}
  class-10-mathematics-annual-exam-2024-1
  class-11-physics-half-yearly-exam-2024-4

slugify() in schemas.py:
  1. lowercase + strip
  2. remove non-word characters (except spaces and hyphens)
  3. replace whitespace/underscores with hyphens
  4. collapse multiple hyphens
  5. append -{id} at end

Pydantic schemas updated:
  PaperOut: @computed_field @property slug → str
  SearchResult: @computed_field @property slug → str
  All paper responses automatically include slug in JSON.

New backend endpoint:
  GET /api/v1/papers/by-slug/{slug}
  Logic: slug.rsplit('-', 1) → extracts numeric ID suffix
  Returns PaperDetail (same as /papers/{id})
  Returns 404 if suffix is not numeric or paper not found

Old route still works: GET /api/v1/papers/{paper_id: int}

Frontend changes:
  services/papers.js: getPaperBySlug(slug) added
  PaperDetailPage.jsx: /^\d+$/.test(id) → numeric → getPaper(id)
                       else → getPaperBySlug(id)
  PaperCard.jsx: link uses paper.slug ?? `/paper/${paper.id}`

Router: no change needed (path: 'paper/:id' handles both)

Verified:
  GET /api/v1/papers/by-slug/class-10-mathematics-annual-exam-2024-1
    → 200, title: "Class 10 Mathematics Annual Exam 2024" ✅
  Browser URL /paper/class-10-mathematics-annual-exam-2024-1
    → Paper detail page loads correctly with breadcrumbs ✅
  Old URL /paper/1
    → Still works (backward compatible) ✅
