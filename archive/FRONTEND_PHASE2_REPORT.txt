WHAT WAS BUILT
==============

A complete public-facing React frontend (React 18 + Vite + Tailwind CSS)
for the TN State Board Learning Platform. All 7 pages are built, styled,
and connected to the live FastAPI backend via Axios.

  - Tailwind CSS 3.4.14
  - React Router v6.27.0 (client-side routing)
  - Axios 1.7.7 (API calls)

====================================================

DESIGN DECISIONS
================

1. Mobile-first responsive design
   - All pages use responsive Tailwind grids (1 → 2 → 3/4 columns)
   - Navbar collapses to hamburger menu on mobile
   - Touch-friendly button sizes

2. No Redux / no Zustand
   - useState + useEffect per page
   - useFetch hook for shared data fetching pattern
   - No global state needed for public-only pages

3. API proxy via Vite (not hardcoded URL)
   - All requests go to /api/v1/... (relative)
   - Vite proxies to FastAPI at localhost:8000 during dev
   - Will work in production if served from same origin OR
     VITE_API_URL env var can be set to an absolute API URL

4. Exam type grouping on frontend
   - SubjectPage groups all exam types into 5 category cards
   - No extra API endpoint needed
   - Counts computed by filtering the full papers list

5. Color-coded class cards
   - Class 9: Blue
   - Class 10: Violet
   - Class 11: Emerald
   - Class 12: Orange

====================================================

PROBLEMS ENCOUNTERED & SOLUTIONS
==================================

1. Problem: SubjectPage needed class name for breadcrumbs, but
   GET /subjects/{id} didn't return class info.
   Solution: Updated SubjectOut schema + endpoint to return
   class_id and class_name fields.

2. Problem: No public "all recent papers" endpoint existed.
   Solution: Added GET /api/v1/papers/recent?limit=N endpoint
   to the papers router.

3. Problem: React Router v6 future flag console warnings.
   Solution: Informational only — not errors. Will add
   v7_startTransition flag in Phase 3 if needed.
