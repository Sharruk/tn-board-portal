FIX REPORT — Vite Preview Issue
TN State Board Learning Platform
Date: 2026-06-20
====================================================

PROBLEM
=======

Replit preview showed:
  "Blocked request. This host is not allowed.
   Add host to server.allowedHosts in vite.config.js"

The React app was running on port 5000 but the Replit
proxy (which serves the preview iframe) was being
rejected by Vite's host validation middleware.

====================================================

ROOT CAUSE
==========

File: frontend/vite.config.js

The allowedHosts option was set to the string 'all':

  allowedHosts: 'all'    ← WRONG (string)

In Vite 5, the correct value to allow all hosts is
the boolean true:

  allowedHosts: true     ← CORRECT (boolean)

Vite 5 does not recognise the string 'all' as a
wildcard. It treats it as a literal hostname to match,
so every request coming from the Replit proxy domain
(*.replit.dev) was rejected with a 403 Blocked.

The Replit preview is served through a proxied iframe
on a different domain from the dev server. Vite's
default host checking blocks requests from unknown
origins unless allowedHosts is explicitly set to true.

====================================================

THE FIX (one line change)
=========================

BEFORE:
  allowedHosts: 'all'

AFTER:
  allowedHosts: true

Also added:
  strictPort: true   ← ensures Vite fails fast if port
                        5000 is unavailable instead of
                        silently switching ports

====================================================

UPDATED vite.config.js
======================

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    host: '0.0.0.0',
    port: 5000,
    allowedHosts: true,     ← FIXED
    strictPort: true,       ← ADDED
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true,
      },
      '/uploads': {
        target: 'http://localhost:8000',
        changeOrigin: true,
      },
    },
  },
})

====================================================

WHAT WAS CHANGED
================

1. allowedHosts: 'all' → allowedHosts: true
   - Allows requests from any hostname/domain
   - Specifically allows the Replit *.replit.dev proxy domain
   - Required for the Replit preview iframe to connect

2. Added strictPort: true
   - Ensures Vite binds exclusively to port 5000
   - Prevents silent fallback to another port if 5000 is busy
   - Makes port conflict errors explicit and easy to diagnose
